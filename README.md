# CraveCraft
AI powered food discovery and personalization cooking experience

Note for Judges:CraveCraft features an integrated AI culinary assistant. Because the AI model runs locally for hackathon privacy and performance, the chat feature requires the backend server to be running.

To test the AI chatbot locally:

1. Ensure you have Node.js installed on your machine.
2. Open your terminal (PowerShell or Bash) in the project root directory.
3. Install dependencies and start the local server:
```bash
node server.js
4. Verify that the server is running on `http://127.0.0.1:3001/api/health` before using the chat interface.
